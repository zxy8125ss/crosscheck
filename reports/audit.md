## 需要修正开发文档的地方

1. **字段都是单行**。每个字段一行写到底，没有跨行内容；解析器按行读即可。
2. **成本标签取值**（全部 677 条都有，五个键齐全）：
   - 钱：`0` / `少` / `多`；时间：`少` / `中` / `多`；毅力：`否` / `些` / `是`
   - 收益：`大` / `中` / `小`
   - 口径：`死亡率` / `金钱` / `时间` / `自由`。界面显示为寿命、钱、时间精力、人身自由。
3. **性价比档的精确算法**（与上游 index.html 一致）：
   - 成本分 = 钱（0→0、少→1、多→2）+ 时间（少→0、中→1、多→2）+ 毅力（否→0、些→1、是→2）
   - 收益大：成本分 0 为极高，1～2 为高，其余为一般
   - 收益中：成本分 0 为高，其余为一般
   - 收益小：一般
4. **争议**只看备注是否以「争议」开头；**待核实**看成本、收益、来源、备注里有没有「待核实」或「TODO」。
5. **证据等级**取「证据等级：」后的第一个字母 A / B / C。
6. **节首导读**：每节第一条之前有 1～12 段导读。一章一章翻时，进入新章节先显示导读。
7. **章节标题行**是 `# N. 标题`，和文件名序号一致（34 节无不一致）。
